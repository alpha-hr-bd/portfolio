ALPHA.HR — FUTURISTIC 3D PORTFOLIO

FILES
- index.html : Main portfolio page
- style.css  : Responsive design, CSS 3D effects and animations
- script.js  : Interactive elastic ID card, scroll reveals and optional sound effects

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.
3. For publishing, upload all three files to the same folder in GitHub Pages or your web host.

NOTES
- Sound is OFF by default. Visitors can enable it using the SOUND OFF control.
- Sound effects are synthesized in the browser; no audio files are required.
- The 3D ID card responds to mouse movement on desktop and remains touch-friendly on mobile.
- Social and contact links are placed in the footer.
