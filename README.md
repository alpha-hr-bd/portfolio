## ⚙️ Installation & Setup

No installation or package manager is required.

### Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The portfolio will open in your browser.
5. Open `builder.html` to access the project builder.

### Clone Repository

```bash
git clone https://github.com/alpha-hr-bd/portfolio.git
```

Navigate into the folder:

```bash
cd portfolio
```

Open `index.html` in your browser.

---

## 🌐 Deploy on GitHub Pages

Follow these steps:

**Step 1:** Open your GitHub repository.

https://github.com/alpha-hr-bd/portfolio

**Step 2:** Upload all project files to the root directory.

**Step 3:** Open:

Settings → Pages

**Step 4:** Under Build and deployment:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

**Step 5:** Click Save.

**Step 6:** Wait for GitHub Pages deployment to complete.

Your portfolio should become available at:

https://alpha-hr-bd.github.io/portfolio/

Your project builder:

https://alpha-hr-bd.github.io/portfolio/builder.html
